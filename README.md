# Реактор

Цепные реакции на одном телефоне или онлайн с другом. Один статичный `index.html`, без сборки.

## Как играть
- Нажми на пустую клетку или на свою, чтобы добавить атом.
- Клетка взрывается, когда атомов в ней столько, сколько у неё соседей (угол 2, край 3, центр 4), и перекрашивает соседей в твой цвет.
- Кто остался без атомов, выбывает.

## Онлайн
«Онлайн» → «Создать комнату» → отправь ссылку или 4-значный код. Связь идёт через Supabase Realtime
(проект `reactor-game`): только каналы broadcast и presence, без таблиц и без хранения данных на сервере.
Ключ в `index.html` публичный (anon), так и задумано.

## Выложить
**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
Через минуту игра будет на `https://<ник>.github.io/reactor/`.

**Vercel:** vercel.com/new → Import этот репозиторий → Deploy (настройки не нужны).
Или из папки проекта: `npx vercel --prod`.

## Обвал (`/obval/`)
Вторая игра в репо — своя механика, домино-дуэль. Ставь костяшку на пустую клетку (и выбери, куда она упадёт)
или обрушь свою стоящую. Падающая костяшка роняет следующую по направлению, всё упавшее в твоей цепи становится
твоим, даже чужое. Очки: 1-я упавшая +1, 2-я +2, 3-я +3… Онлайн через тот же Supabase-проект.
Адрес на Pages: `https://<ник>.github.io/reactor/obval/`

## Сумо на льду (`/sumo/`)
Третья игра в репо. У каждого по три шайбы на круглой льдине. Оба тайно целятся (оттянуть шайбу, как рогатку),
потом все шайбы летят одновременно. Кто выехал за край, тот падает в воду. С третьего раунда льдина тает по краю.
Усилялки на льду: ⚡ Турбо, 🪨 Камень, 💥 Бомба, 👻 Призрак, ❤️ Жизнь. Подобрал, проехав по ней, включил на свою шайбу.
Онлайн через тот же Supabase-проект: по сети идут только планы ходов, физика детерминированная и одинаково
считается на обоих телефонах. Есть игра на одном телефоне и против бота.
Адрес на Pages: `https://<ник>.github.io/reactor/sumo/`

## Блеф-кости (`/blef/`)
Четвёртая игра в репо. У каждого 5 скрытых кубиков. Ставки на все кубики на столе («минимум 4 пятёрки»),
единицы — джокеры и самая старшая грань (2 < 3 < 4 < 5 < 6 < 1). Повышать можно только вверх: количество
и/или грань, ничего не опуская. Ответ: повысить, «Не верю!» (вскрыть) или «Точно!» (ровно столько, угадал — кубик назад).
Раз за игру можно подглядеть один чужой кубик и раз перебросить свои. 2–4 игрока онлайн или против ботов.
Онлайн через тот же Supabase-проект, кубики детерминированы от кода комнаты, по сети идут только ходы.
Адрес на Pages: `https://<ник>.github.io/reactor/blef/`

## Ограбление (`/heist/`)
Кооператив по звонку. Вор видит только клетки рядом с собой (ночное зрение) и читает записки с кодами.
Штурман видит весь план-чертёж: охрану с маршрутами, камеры, обычные и мигающие лазеры, и ведёт вора голосом,
а код от двери вводит сам. Всё движется только когда вор делает ход. Уровни бесконечные: генерируются из кода
комнаты, и решатель проверяет, что каждый проходим. Механики вводятся постепенно, с 6-го дела бывает «компас сломан».
Роли меняются каждый уровень. Есть «Тренировка одному», где видно всё.
Адрес на Pages: `https://<ник>.github.io/reactor/heist/`
